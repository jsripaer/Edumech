# English

On my mechanics course, it's usual to find myself struggle imagining the motion of complex systems. As students learning physics they always want to figure out how the systems behave, but that not easy for most of us and most of systems.

 How can computer help with this? I told myself it worths a try.

So I decided to make a simple tool to help me visualize the motion of systems.
 What features do I need?
- It has to be easy to use and intuitive.
- It has to be lightweight for classroom experiments.
- It has to be redesingable for different imitations.

Sure a physics engine is not a rare thing, but most of them are too complex for teaching and some of them are not open. I don't think they fit teachers who are not experienced in programming. For most scene an AI angent can make scripts with Python. But how if I can produce an integrated environment that enables simpler scripts, more powerful imitation and physical taste logic? Look how GeoGebra changed the mathematics leraing style around the world! And I need a small project to practice Python programming. Thus I started this.

# 中文

在力学课程中，我经常发现自己难以想象复杂系统的运动。作为学习物理的学生，他们总是想弄清
楚系统是如何表现的，但这对我们大多数人来说并不容易，对大多数力学系统来说也不容易。
计算机能否帮助解决这个问题？这值得一试。

所以我决定制作一个简单的工具来帮助我可视化系统的运动。我需要哪些功能？
- 它必须易于使用且直观。
- 它必须轻量级，适合课堂实验。
- 它必须可重新设计，以适应不同的模拟。

当然，物理引擎并不罕见。但大多数都太复杂，不适合教学，有些不是开源使用的。我认为它们不适合没有编程经验的物理老师。对于大多数场景，一个AI可以编写令人满意的Python脚本。但如果我可以制作一个集成环境，使脚本更简单，模仿更强大，使用更具“物理味”呢？看看GeoGebra对数学课有多么好的帮助！而我正好需要一个小项目来练习Python编程。因此，我开启了这个项目。
